# Security

data-room-organizer reads local files and writes copies into a separate room folder. It
never changes, moves or deletes the source documents, and the core makes no network
calls. The Google Drive connector (roadmap phase 7) will work against a test Drive in
this repository's examples.

Data rooms hold sensitive documents. Point the tool only at folders you are allowed to
read, and keep real rooms out of this repository.

To report a vulnerability, open a private security advisory on the repository rather than
a public issue.
